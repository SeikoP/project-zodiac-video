# tools/livestream-pk

- The host streams straight from **TikTok LIVE Studio** (a Web/Link source pointing at the overlay, via `npm run share` for the https address). They do **not** use OBS.
- Do not run, edit, install or "fix" anything OBS-related: `obs/`, `Mo-OBS.bat`, `scripts/setup-obs.mjs`, `npm run obs`, or the OBS notes in README. Leave them as they are unless the user asks for OBS by name.
- When checking the overlay, use the browser at `http://127.0.0.1:4848/` (or the share URL), not OBS.
