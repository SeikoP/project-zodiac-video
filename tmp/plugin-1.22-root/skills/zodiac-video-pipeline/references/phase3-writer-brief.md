# Phase3WriterBrief

Compile this from the full narrative plan before sending context to the narration writer.

```yaml
sign: <label>
topic: <plain-language focus>
delivery_mode: direct | conversational
audience_vibe: student_peer | neutral | custom
thesis: <one sentence>
evidence_safe_behaviors:
  - <observable supported behavior/tension>
situation_territories:
  - <context only; not an exact beat script>
narrator_vibe:
  - <2–4 qualities, e.g. chatty, lightly teasing, quick reactions>
motif_candidates:
  - <optional metaphor/payoff image>
forbidden_claims:
  - <unsupported motive/cause/consequence/frequency/outcome>
```

Rules:
- keep this brief short enough to read at a glance;
- no beat IDs;
- no evidence taxonomy labels;
- no devices array;
- no exact number of jokes/reactions/contradictions;
- no asset, animation, runtime, package or QC instructions;
- do not paste the full narrative plan underneath it.

For current Conversational work, default `audience_vibe: student_peer` unless the user asks otherwise.
