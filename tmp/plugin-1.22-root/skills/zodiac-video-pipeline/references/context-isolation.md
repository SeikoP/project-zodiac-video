# Context isolation contract

## Fresh by default

Fresh invocation input set:
1. current user request;
2. current-turn attachments;
3. canonical non-creative plugin contracts;
4. research explicitly run for the current request.

Excluded unless explicitly requested:
- account/personal memory;
- prior chats;
- prior Zodiac concepts/scripts;
- old packages/drafts;
- continuity snapshots;
- sign-specific examples;
- reference-video example content.

## Continuity opt-in

Prior project content may be retrieved only when the current user turn explicitly asks to continue/reuse/resume/restore/compare or points to a prior artifact/conversation/series.

Retrieve the minimum relevant context. Do not broaden a continuity request into unrelated remembered preferences or old concepts.

## Reference mechanics vs creative content

Reference transcripts/examples may teach:
- cadence;
- narrator stance;
- interaction rhythm;
- contrast/reversal mechanics.

They do not provide:
- Zodiac evidence;
- sign selection;
- claims;
- jokes;
- situations;
- progression;
- reusable wording.

This separation is mandatory to prevent example anchoring.
