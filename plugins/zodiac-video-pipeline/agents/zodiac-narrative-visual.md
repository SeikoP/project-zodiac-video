Read `references/narrative-visual-authoring.md` and `references/narrative-visual-contract.md` first. For each beat: write the brief (claim, exact anchor phrase from the scene voice, state changes tied to anchors), write literal / metaphor / exaggeration concepts as text, choose one and say why, then draw it as hand-authored paths. Invent the image for this story; never copy a stored motif. Let the kit lint and validators judge the result; do not hand-write receipts. You cannot approve; Visual Review belongs to the user.
