# Conditional plugin use

## Core-first rule
Phase 1 must be able to reach every required quality gate without any enhancement plugin. A plugin becomes required only when a regression test demonstrates a material correctness/quality capability the native core cannot provide.

Classify integrations as:
- **core** — required for contract correctness or source acquisition with no equivalent native path;
- **optional** — invoked only for a named failure mode;
- **obsolete** — duplicates native ownership or adds no material gain; remove it from the critical path.

Zodiac owns evidence, premise, sign identity, voice, narration and approval. Video Lab does not replace Phase 1. Use leaf guidance only for an observed weakness:
- hook_promise → optional hook guidance after premise selection;
- pacing/clarity → optional script review after native editorial review identifies the issue;
- visual_expression → Phase 2 only;
- natural_voice / formulaic_language / audience_fit → native targeted revision first. Humanizer, when separately available, is an optional surgical fallback only.

Supply actual excerpt, selected premise, intended improvement and constraints. Scores are opinions, not retention evidence. Do not impose hook word counts, CTA, a visual per sentence, new assets per shot or pre-TTS measured timing. Storyboard uses existing native states/bindings; reject unsupported motion. No VideoGen dependency, paid provider or auto switch of renderer is added. Guidance presentation/advertising remains outside narration and production artifacts.

Use plan-plugin-use.mjs <root> --write with plugin-use-request.json {phase,weaknesses:[{kind,excerpt}],availableSkills:[{id,uri}]}. Inventory must reflect observed installed leaf skills. This writes REQUESTED decisions only; it does not claim calls. After real reads, record APPLIED/REJECTED with guidance_uri, skill_read_ref and concrete application_summary; unavailable skill uses NATIVE_REVIEW, no execution proof. For evidence/sign_identity/premise use NATIVE_REQUIRED. Empty decisions are valid when no weakness requires a plugin. Validate without --write before Concept commit. An unresolved request blocks; never call every installed plugin to fill receipts.

Exa/Tavily handle discovery; Parallel or documented fallback corroborates using independent sources. Firecrawl only extracts difficult pages. Content research plugin supplies bounded facets/provenance when needed. Viral/human-touch leaf skills address a named issue and retain their actual origin. Humanizer is not part of the default web critical path and must never be the second writer. If used, constrain it to the exact failing excerpt and failure class; preserve facts, evidence qualifiers, narrator relationship, controlled roughness, progression and payoff. Its absence never blocks Phase 1. vidIQ is optional authorized channel/reference data. Remotion belongs to local preview/render; Superpowers belongs to system development. Do not fabricate plugin execution or independent reviewers.
