# Context-first environment routing — v2.2.30

**Problem:** The content engine repeatedly puts the characters in class because its visible canonical environment guidance emphasizes bedroom, classroom and hallway. The real V4 composition catalog already contains non-school profiles. This is a *semantic routing* issue before it is an asset count issue.

## Authoring order
1. In Phase 01 choose the personality facet/identity tension and the most revealing situation territory **without considering currently convenient asset profiles**.
2. Keep contexts varied across the series. Do not assume `student_peer`, classroom, homework, group projects, exams, crush or campus for every fresh Zodiac idea. An explicit school-centered concept remains valid.
3. In Phase 02 choose the existing V4 profile that truthfully matches the authored situation. Use the native `composition-index.json` profiles, not hand-invented IDs. Existing environment examples include bedroom, living room, kitchen, entry, cafe, outdoor street, library, classroom and hallway; verify precise ID in the live catalog.
4. Where a context is unsupported by current structural cues, prefer an honest minimal/micro-environment or add a native V4 profile + actual cue SVG + catalog wiring + tests before claiming coverage. Never rename an existing school profile to represent another place.
5. Preserve the approved narration: asset shortage cannot rewrite a user-approved story into a classroom, nor justify selecting `micro_story`.
6. Record an editorial reason for each environment selection; location changes need a real story shift. Within one environment, use foreground/shot/focus changes before unnecessary location changes.

## Candidate territories (concept exploration, NOT preset assets)
Cafe conversation; living-room sofa chat; kitchen family exchange; bedroom/late-night reflection; doorstep farewell; street/walk encounter; game or hobby hangout; public-transport waiting; online chat/phone call; shopping; close friendship conflict; personal decision alone. Choose from evidence/topic naturally, not to satisfy a quota.

## Gap audit
Before drawing new cues, list existing profiles and actual SVG assets, group desired missing territories by narrative need, prioritize broadly reusable cues, then update V4 composition catalog and structural assets together. A text-only policy does not add actual renderable backgrounds. Do not claim new environments available until native compilations and tests pass. Preserve spatial/foreground/caption safety contracts.
