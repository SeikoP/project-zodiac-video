# Approved Content Refresh — Viral + Search

Use this only when the user explicitly asks to improve already-approved narration/content.

## Required sequence
1. Treat the approved script as the semantic baseline. Extract its micro-behaviors, tension, payoff, evidence boundary, story shape and delivery mode before changing wording. Do not switch Direct ↔ Conversational unless the user asked for a rewrite or the current delivery is the explicit optimization target.
2. Run the selected Viral/QS–PT–ĐK workflow on that baseline: observe, analyze structure/phrasing, identify special points, form A/B hypotheses, and derive a reusable formula.
3. If Exa is explicitly requested, use Exa to research current or older phrase/trend mechanisms. Prefer documented context and flexible reaction/contrast structures.
4. Apply trend language sparingly as hook, reaction or punchline. Rephrase into the video's own voice; do not copy scripts or force every trend found into the narration.
5. Keep only changes that strengthen stop-power, pacing, contrast, memorability or commentability without adding unsupported motive/cause/frequency/outcome claims.
6. Recompile scene voice anchors and visual progression after narration changes.
7. Write `CONTENT_REFRESH_RECEIPT.md` into the package: baseline summary, viral observations, sources reviewed, phrases/mechanisms borrowed, exact semantic changes, A/B hypothesis and risks.

## Availability rule
If the user explicitly selected Viral, Exa, PDF or another helper plugin and it is unavailable, disconnected, rate-limited in a way that blocks the requested phase, or its required skill/tool cannot be read, STOP that phase and ask the user to load/reconnect it. Never silently substitute another provider.

## Trend rule
Trend phrases may be old or current. Treat them as linguistic mechanisms, not evidence. Prefer short reaction frames, contrast, reversal, curiosity gaps and remixable everyday wording. Astrology remains entertainment framing; do not present zodiac generalizations as scientific facts.
