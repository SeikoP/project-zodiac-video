# Asset routing

`references/asset-library-v4/` is the sole current asset source.
Use its `selection-guide.md` and current catalog surface. Select character
identity once, plan states before generation, compile native assets and validate
exact geometry/lineage. Character states change pose/expression, not identity.
Scene-set, actor staging, physical props, symbolic objects and effects have
independent responsibilities. Historical recovery uses an external pinned
snapshot; the current package contains no migration guide or old master catalog.
