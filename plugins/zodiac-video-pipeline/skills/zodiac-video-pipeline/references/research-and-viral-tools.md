# Research routing by phase

Research-First is the default unless the user requests a Writer Context. Keep astrology interpretation, editorial inference, fiction, and language evidence separate. Use `orchestration/router.md` for capability, context and handoff ownership rules.

## Phase 1 — Evidence and topic

**Exa** is the discovery route: find candidate sign + everyday-theme combinations and astrology sources using 1–2 distinct workstreams, usually 6–10 results each. Avoid duplicate synonym searches.

**Parallel Search** verifies the selected central claim only. Use 2–3 useful angles to confirm independent support, exact placement/scope, and material conflicts. Fetch a found URL with its originating provider first; switch only if fetching fails or important context is missing.

**Firecrawl** is conditional extraction/crawl support for a relevant page that is hard to read or a specific bounded crawl need. Do not crawl when normal fetch provides enough context.

**Fallback:** Tavily is optional, as is built-in web search. If Exa or Parallel Search fails, rate-limits, or returns unusable sources, stop retrying that route for the turn and switch once to an accessible fallback. Report the layer that was unavailable; do not claim a fallback ran if it did not.

Stop when at least two independent useful sources support the central claim, placement/scope are clear, and no material conflict remains. Do not search slang, current phrases, hooks, trends, or Vietnamese prose in Phase 1. Keep a compact evidence ledger with source/date, language/region, placement, supported interpretation, corroboration/conflict, confidence, and story permission.

## Phase 1 — Concept, hook and story

Use vidIQ only for relevant short-form creator/reference mechanisms; it is not Zodiac evidence and is not a required preflight. If the user supplied a reference, the viral-content-analyst can analyze the observable material and mark missing visuals, audio, metrics, or context unknown. Use the viral-headline-writer for hook candidates after the editorial point and story engine exist. See the orchestration reference for its constrained brief and selection gate.

Do not call a hook pattern recurring without at least three independent relevant creators. One source or inaccessible video can support only a limited observation or hypothesis.

## Narration step — Vietnamese dialogue and trend polish

First apply the Narration-step writer sequence and line audit defined in the orchestration reference. A SEARCH tag is an optional editorial need, not permission for the Narration writer to call tools. Route language research through Evidence/Concept with a real external_tool_call operation; return only a sourced language note to the writer. Search only approved unresolved language questions. Search by function, not bulk slang keyword: surprise, interruption, disbelief, escalation, transition, teasing, punchline, mock seriousness, or casual dialogue.

Parallel Search is primary. Use Exa only for deeper semantic discovery or when Parallel coverage is insufficient. Tavily is fallback. Sforum and similar roundups are phrase corpora, not sole proof of current usage; check other dated social/editorial/platform examples where available.

Classify findings:
- **Observed wording:** directly seen in an accessed source.
- **Recurring usage:** similar function/wording appears across independent examples.
- **Trend candidate:** dated/current examples exist but growth is unproven.
- **Measured trend:** dated platform, region, and time-window data show rising use.

Do not infer a measured trend from one post, one roundup, or search-result counts. Preserve natural spoken Vietnamese; reject slang that sounds forced, stale, text-only, hard to say, or changes the character. Language evidence never supports a Zodiac trait.
