# V4 meme template contracts

This folder owns the semantic JSON contracts used by the 11 V4 adapters. The old reference SVGs were not copied into the production library. Each adapter points to one local JSON contract and supplies V4 frame, mechanic, role, acting, and effect bindings.

`index.json` is the template registry. Run `../validate-meme-templates.mjs` after editing a template or adapter.
