# Interactive props as physical storytelling

Select a prop from an action in the approved narration: someone drives, hands over, checks, blocks, avoids, opens or returns to something. A prop may carry the episode's ongoing action, not only sit beside a talking actor. Do not invent a setting, prop or event to fill a quota. Reuse an ordinary item when its behavior changes the story. Narrative Visual still belongs to Phase1 direction; Story Text and Scene Accent have separate roles.

Before browsing assets, author the causal chain in existing Visual Intent fields:

1. Establish who uses the object and the normal state, at an exact spoken anchor.
2. Stage the action or obstacle through actual state/motion events. Name the actor-prop relation and its story consequence in `experience_profile.story_focus.links` and event `action`, then bind physical geometry in `spatial_bindings`.
3. Show the consequence, changed choice or reaction. A callback should reuse the object's recognizable identity with changed meaning when the story supports it.

Use existing `required_physical_entities` only for objects the story actually requires. No minimum number of props, states, scenes or callbacks. Preserve sparse reflection and simple scenes. Never label a decorative sticker interactive just to increase coverage.

| Situation | Setup -> action -> result | Physical review |
| --- | --- | --- |
| Car, familiar route | Cruise -> road closes/turns -> detour becomes familiar | Driver and car move together; wheels/hands stay readable; obstacle ahead; detour distinct |
| Phone, an unanswered message | Hold phone -> offer/retract reply -> put it away | Phone reaches performed hand; screen state and gaze change at the spoken decision |
| Cup, remembered preference | Offer cup -> recipient checks/accepts -> recognition | Handoff and gaze connect both actors; item remains visible at contact |
| Notebook, changing a plan | Open page -> cross out/rewrite -> commit or hesitate | Hand reaches the page; text does not replace the actual action |

Reuse current catalog IDs; author a derivative only for a specific missing physical state. Prefer motion on the same SVG for travel/rotation. Contacts, layer order, entrances/releases and meaningful state changes matter more than asset count. Keep the main action readable at 270x480 without hiding faces/captions. Avoid making every prop large; increase prominence during the relevant action and release attention afterward.

The scene-experience gate rejects per-prop no-op actions in behavior/relationship scenes. It cannot certify causality, plausible motion, humor or viewer readability: inspect setup/action/result frames, and later actual timed animation. The car/pothole/barrier kit is reusable geometry, not a template story to repeat in every sign video.
