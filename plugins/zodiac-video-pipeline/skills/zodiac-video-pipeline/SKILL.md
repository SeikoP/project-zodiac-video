# Zodiac Video Pipeline

Follow orchestration/router.md: 01-content → 02-visual-production → 03-handoff. Fresh Run Isolation: do NOT use account/personal memory; do NOT auto-load old approved packages. Preserve evidenced approvals.

Verify live/source entry with orchestration/verify-entry-freshness.mjs before fresh Evidence. Use verified GitHub Actions source-artifact fallback. Bootstrap verified local or checksummed restored source through orchestration/execution-bootstrap.md and execution-preflight.mjs. Plugin Creator updates source; it is not production source transport.

Phase 01: read references/episode-formats.md, content-quality-engine.md, phase01-briefing.md and plugin-use-playbook.md. Set episode_selected for new scoped episodes; persist research-scope → episode-scope. Choose single_sign, element_group, ranked_shortlist or comparison. Keep three premises, evidence-bound member lenses, one Story Spine/payoff. Compile bounded writer context; separate draft/review scopes. Zodiac owns research and approval; Video Lab is conditional leaf guidance.

Use Narrative 2.1 for scoped episodes; preserve reviewed 2.0 readers. Follow references/narration-rhythm.md and TONE_RHYTHM_DEFAULT. Run references/short-form-duration.mjs before Content Review. Review evidence, identity, motif, pronunciation and actual narration; estimates are not measured audio. Commit genuine receipts via orchestration/commit-phase01-step.mjs. No automatic creative PASS; require user approval at IN_REVIEW.

Phase 02 has three user actions: chọn khung/cast/ý hình; biên dịch và sửa cumulative preview; duyệt hình rồi handoff. Native manifest retains ownership and gates. Prefer one .authoring/visual-intent.json when complete; projections are derived. Legacy sources remain supported.

Read references/character-depth-v2.md, character-viral-performance.md, character-design-intent.md, director-performance-v2.md and design.md. Plan Character Assembly @2 and Director before SVG; set state count by action. Renderer does not animate limb groups. Keep Human Stroke v2, Visual Grammar v4, native V4 assets, contacts/layout/lifecycle. Scoped episodes require episode-cast-plan. Use orchestration/derive-scene-context.mjs for bounded scene context.

Use references/asset-library-v4/selection-policy.json and orchestration/plan-step-context.mjs for selected guidance. structural environment cues are explicit. Archive frames preserve exact ZIP SVG/transform/clipping, wall/floor and flat depth; no automatic extras, perspective, shadows or gradients. Read references/environment-frame-system.md, background-only-policy.md, asset-use-playbook.md and orchestration/scene-art-direction.md.

Follow references/story-object-effects.md and story-object-composition-v2.md. Record required/optional/omitted with reason/review_ref; required flags cannot disappear. Object action must carry meaning; repeated reveal is weak. Require human mute-review.

Cover uses references/cover-composition-v2.md, opening narration and honest episode identity. Run orchestration/run-director-v2-review.mjs after compilers, with orchestration/build-native-preview-pairs.mjs and orchestration/validate-native-preview-pairs.mjs for cumulative endpoints. Metadata cannot prove pixels/prosody.

Phase 03: orchestration/run-phase03-production.mjs is the only export entrypoint; pass approved --episode-scope when scoped. Preserve zodiac-job@5/zodiac-renderer@2.0.1, stable identity, legacy zodiac-<sign>-<concept> naming and one ZIP/revision. Seal reviews/source; validate contracts and ZIP roundtrip. Return ZIP-bound receipt. The local runner owns TTS/timing/Remotion/MP4/audio/frame QA; ZIP-ready is not video-ready.
