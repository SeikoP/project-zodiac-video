## Execution source after refactor
Before native execution, read orchestration/execution-bootstrap.md. Use a verified **phase-scoped execution bundle** for the current phase. Never clone/download the whole repository as runtime context. A repository file listing, skill read, or connector response is not executable source on the host filesystem. Source transport must not bypass the active router, phase manifest, validator order, source hashes, or review gates.

Phase 01: use references/episode-formats.md and references/phase01-briefing.md. Distinguish episode format from the character_deconstruction story engine. Use bounded independent evidence, one coherent Story Spine and authentic Content Review. Narrative 2.1 is for fresh scoped episodes.

At Phase 01 → Phase 02, run the transition gate until AUTHORING_READY, then run orchestration/activate-phase02.mjs before Phase 02 step commits. Activation changes orchestration state only and creates no approval or native PASS. Inspect source hashes/approvals; AUTHORING_READY is not PASS.

Phase 02: read orchestration/phases/02-visual-production.md and references/asset-library-v4/selection-guide.md. Use features/asset-selection/build-current-asset-review.mjs for native catalog comparisons. Use approved cast, scene set, V4 native assets and stateful visual metaphors without replacing backgrounds. Compile scene-complete native review frames for every scene plus event endpoint pairs; Visual Review must use the clean Phase-02 review surface produced by orchestration/prepare-phase02-review.mjs. Do not copy historical Phase-01 README or migration prose into the review surface. Scene accents stay inside the scene wall.

Phase 03: use orchestration/run-phase03-production.mjs or its verified current target. Preserve zodiac-job@5 and zodiac-renderer@2.0.1. Package one validated ZIP per revision. Local runner owns voice, timing, Remotion, captions, cover, audio and MP4 acceptance. ZIP-ready never means video-ready.

Fresh Run Isolation: old episode examples, migration prose and retired assets are absent from the current selection surface. Missing choices block; no legacy/selected-cues fallback. Historical job recovery requires its separately pinned external snapshot. The scene-set is a supporting rear picture/wall, not the actor stage or a physical surface. Foreground character composition is independent; only backdrop accents are wall-contained.

Current visual selection uses a fixed native face, plain or intrinsic zodiac-glyph shirts with selected colors, no accessories and no separate reaction/effect assets. Preserve the sign's icon baked on its shirt; omit decorative halos, rays and floating marks around that icon. Never infer a supporting actor's sign. Prefer feminine presentation with a tall slim silhouette for leads unless explicit episode design requests otherwise. Preserve pose/expression acting, props, symbolic story objects and supporting backdrops.

Phase 02 scene accents require an explicit decision for every scene-set: select native `scene_accents`, or write a non-empty `scene_accent_omission_reason` in the environment. Empty arrays alone fail art-direction preflight. Select context cues supported by the approved narration; do not auto-decorate. Default registry accent placement follows the transformed rear wall, while authored transforms remain canvas coordinates. Keep actor slots and physical support separate from the backdrop. Review whole-scene and event endpoints after any geometry or source change; invalidate stale evidence instead of copying approvals.

Scene accents are sparse narrative context cues, not a permanently decorated room. Their `initial_state` and boolean visibility `states` may be driven by ordinary voice-anchored events, reusing one SVG. Define when each cue enters and leaves; string lights suit a narrated birthday, while cafe cues only accompany the cafe passage. One continuous scene can contain many visual story turns. Story Objects carry changing meaning independently of backdrop accents; a V2 setup/friction/payoff may play within one native scene without splitting approved narration paragraphs.

Fresh Phase 02 requires per-beat visual_coverage in Visual Intent art_direction before SVG compilation. Fill actor, backdrop, accent, Story Object, ordinary prop, support and caption decisions with actual references or explicit omissions. The native seam and Visual Quality enforce coverage; a symbolic metaphor cannot substitute for ordinary props used by the narration.
