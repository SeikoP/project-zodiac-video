# Zodiac Studio — Visual Production (Phase 2)

Phase 2 turns the **approved narration** (locked, with measured voice timing) into one canonical **Visual Intent** that compiles to a HyperFrames composition. Studio's Core owns everything deterministic; the agent owns the creative decisions. A scene is correct when a muted viewer can follow who does what, where, and why it matters.

## The one idea behind every rule
**Story first, library second.** Decide the viewer read of each beat (who, what changes, what it means) before looking at any catalog. The catalog supplies vocabulary only. Never add a component to make a checklist green: every element must carry a fact the narration states or the viewer needs. Sparse is valid when the omission is deliberate and explained.

## Who owns what
| Core (deterministic, never asked of the agent) | Agent (creative, bounded) |
| --- | --- |
| scene ids, narration ranges, asset keys, hashes, merge | cast design, scene story, setting, props, acting |
| coordinates, layers, floor line, caption lane, canvas bounds | which things appear and what they do |
| exact voice-anchor text, event timing, one-event-per-target spacing | which anchor each beat lands on, the short action phrase |
| one prop per family, no overlaps, frame/mechanic compatibility | choosing from menus; never inventing ids |
| approvals (never created by automation) | proposing only; a human gives Visual Review |

A missing prop, pose or art is **never fabricated**: it is a request recorded for new master art (`NEW_VARIANT_MASTER_REQUIRED`).
